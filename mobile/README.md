# Empaquetado Móvil (Android / iOS)

Este directorio centraliza la configuración nativa para **Capacitor** y complementa el proyecto **Tauri v2 Mobile** ubicado en `../src-tauri/`.

- **App ID / Package:** `com.costudio.gestorhorarios`
- **Web Assets:** `../dist` (generado con `npm run build` y `base: './'` en `vite.config.ts`)
- **Tauri Android:** `npm run tauri android build`
